# CLAUDE.md

turnmap: a client-side visualizer for Pydantic AI message histories. Two deliverables, one
npm workspaces monorepo (npm, node 24, no pnpm):

- `packages/turnmap`: the `turnmap` npm package. React 19 component plus the pure functions
  `parseMessages`, `buildGraph`, `layoutGraph` and the schema types. Vite lib mode (es + cjs),
  `vite-plugin-dts`, Tailwind v4 with the `tm:` prefix and no preflight, `@xyflow/react` and
  `@dagrejs/dagre` bundled, React as a peer dependency. One stylesheet, `turnmap/styles.css`.
- `apps/site`: the public site (Vite, React 19, Tailwind v4, shadcn-style components in
  `src/components/ui`), deployed to GitHub Pages. It imports the built package (`dist`), so
  rebuild the library after changing it.
- `examples/`: fixtures generated by `examples/generate.py` with pydantic-ai's
  `FunctionModel` / `TestModel`. Regenerate rather than hand-edit so they match the real schema.

## Commands

```bash
npm install
npm run dev            # site dev server
npm run build:lib      # must precede build:site and the site dev server after lib changes
npm test               # vitest in packages/turnmap
npm run lint && npm run typecheck && npm run format:check
```

## Conventions

- Prettier: no semicolons, double quotes, printWidth 80. ESLint flat config at the root.
- No em dashes in any text (code, comments, docs, UI copy, commit messages). Use commas,
  colons, parentheses or separate sentences.
- The schema mirror in `packages/turnmap/src/schema.ts` follows
  `pydantic_ai/messages.py`. Keep every field optional that pydantic-ai may omit; never
  drop unknown parts (they render as raw JSON).
- The graph rules are documented in `README.md` ("The graph") and tested in
  `packages/turnmap/test/graph.test.ts`. Change both together.
- The library stylesheet declares `@layer theme, base, components, utilities;` first so a
  host page's Tailwind build keeps the standard layer order. Keep that line.
- Part nodes get `initialWidth` / `initialHeight` from the layout, never `width` / `height`
  (those would force the DOM size). The canvas relayouts from measured sizes.

## Release

- Site: pushes to `main` deploy via `.github/workflows/deploy-site.yml`. The base path is
  `/` when `apps/site/public/CNAME` exists (custom domain), else `/turnmap/`.
- npm: bump `version` in `packages/turnmap/package.json`, push, publish a GitHub Release
  tagged `vX.Y.Z`; `publish-npm.yml` publishes with trusted publishing and provenance.
